HOMELAB WATCHDOG

> U5 · BMC, WHO WATCHES THE HOME SERVER

utsav@homelab:~/homelab/watchdog$ cat README.md

Monitoring that lives on the same box it is monitoring is not real monitoring. If the home server goes down, its own alerting goes down with it. So there is a second, tiny Raspberry Pi Zero W whose entire job is watching the home server from the outside and staying quiet unless something is actually wrong.

utsav@homelab:~/homelab/watchdog$ ./features --list
▸ Pings the home server every 10 seconds ▸ Alerts after 3 consecutive missed replies, not just one blip ▸ Own Tailscale identity, resolves public DNS independently ▸ Deliberately kept dumb and separate, one job, done reliably
