A Raspberry Pi 4 that started as a university side project years ago, sat dormant for a while, then got a ground up rebuild this year. Now runs a full Docker media stack, Pi-hole filtering 2.4M+ domains for the whole network, a Caddy reverse proxy with clean local domains, and a Telegram monitoring suite of 14 scripts across two bots. U5 · BMC, WATCHDOG
Homelab Watchdog
A second, independent Raspberry Pi Zero W with one job: watch the home server and say something if it goes quiet. Pings it every 10 seconds over Tailscale, alerts after 3 missed replies, and deliberately stays on its own separate network path so it can still reach the outside world if the main Pi goes down.
